# Kuzey Diş Polikliniği — Demo Klinik Sitesi

Diş klinikleri ve poliklinikler için hazırladığım tanıtım sitesi örneği. Klinik ve hekimler hayalidir.

**Canlı demo:** https://ibrahimkaandeger.github.io/kuzey-dis-demo/

## Özellikler
- Mobil uyumlu, framework'süz (HTML / CSS / JavaScript), hızlı açılış
- Tedavi kartları → tek tıkla randevu formuna o tedaviyle geçiş
- Randevu talebi formu → hazır mesajla WhatsApp'a yönlendirme (Pazar günü seçilemez)
- KVKK onay kutusu ve aydınlatma metni penceresi
- Çalışma saatlerine göre canlı "Şu an açığız / kapalıyız" durumu ve bir sonraki açılış
- Hekim tanıtımları, klinik galerisi, SSS, harita
- Footer'da mesul müdür bilgisi
- Hasta yorumu, öncesi/sonrası görseli ve fiyat listesi içermez (sağlık hizmeti tanıtımında dikkat edilen konular)
- SEO: meta etiketleri, Open Graph, schema.org `Dentist` verisi

## Yeni müşteriye uyarlama
`script.js` başındaki ayarları değiştirmek yeterli: WhatsApp numarası, çalışma saatleri, tedavi listesi.
Görseller `img/` klasöründe.

Görseller yerel olarak Z-Image modeliyle üretilmiştir.
